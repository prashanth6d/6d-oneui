Developer Usage Rules
1
One Primary per section — never place two .btn-primary side-by-side. Use Secondary for the second action.
2
Danger confirmation pairing — always pair .btn-danger with a Cancel (.btn-tertiary) in a modal or destructive flow.
3
Text buttons for inline context only — never use .btn-text-* as a standalone page CTA. Reserve for table actions, inline links, and supporting copy.
4
Icon buttons require a label — never icon-only unless in a collapsed/toolbar context (add a tooltip when icon-only is unavoidable).
5
Disabled state — apply both [disabled] attribute AND .btn-disabled class. Always use cursor: default — NOT cursor: not-allowed. Same rule for disabled toggles.
6
No custom colours — never override button colours outside the defined tokens above. All colours are locked to the 6D brand palette.
